# Monsoon Preparedness AI

A GenAI-powered monsoon preparedness solution that provides personalized weather alerts, safety recommendations, and emergency guidance using real-time data and Google's Gemini AI.

## 🌟 Features

### Core Features
- **Real-time Weather Dashboard**: Live weather data with 5-day forecasts using OpenWeatherMap API
- **AI-Powered Preparedness Plans**: Personalized emergency plans generated by Google Gemini AI
- **Emergency Checklists**: Dynamic checklists for various scenarios (floods, cyclones, evacuations)
- **Travel Advisory**: AI-generated travel recommendations based on weather conditions
- **Safety Recommendations**: Comprehensive safety tips for different weather scenarios
- **Real-time Alerts**: Automated weather alerts with severity levels
- **Multilingual Support**: AI-powered translation for 12+ languages
- **AI Chat Assistant**: Interactive chat for monsoon preparedness queries

### Technical Highlights
- **No Hardcoded Data**: All features use real API calls
- **Google Services Integration**: Firebase for authentication, Firestore for data storage, Cloud Messaging for push notifications
- **GenAI Integration**: Google Gemini API for all AI-powered features
- **Accessibility**: WCAG compliant with ARIA labels and keyboard navigation
- **Responsive Design**: Mobile-first approach with TailwindCSS
- **Comprehensive Testing**: Unit tests with Vitest

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ and npm/yarn
- Google Gemini API Key
- OpenWeatherMap API Key
- Firebase Project (optional, for full features)

### API Keys Setup

#### 1. Google Gemini API Key
1. Go to [Google AI Studio](https://makersuite.google.com/app/apikey)
2. Create a new API key
3. Copy the key for environment setup

#### 2. OpenWeatherMap API Key
1. Go to [OpenWeatherMap](https://openweathermap.org/api)
2. Sign up for a free account
3. Navigate to API keys section
4. Copy your API key

#### 3. Firebase Setup (Optional)
1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Create a new project
3. Enable Authentication (Email/Password)
4. Create Firestore Database
5. Enable Cloud Messaging (for push notifications)
6. Copy your Firebase config

### Installation

1. Clone the repository:
```bash
cd c:/Users/NANDAGIRI\ MYTHRI/Downloads/GENAI
```

2. Install dependencies:
```bash
npm install
```

3. Create `.env` file:
```bash
cp .env.example .env
```

4. Add your API keys to `.env`:
```env
VITE_GEMINI_API_KEY=your_gemini_api_key_here
VITE_OPENWEATHER_API_KEY=your_openweather_api_key_here
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_project_id.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_project_id.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```

### Running the Application

Development mode:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

Preview production build:
```bash
npm run preview
```

### Running Tests

Run all tests:
```bash
npm test
```

Run tests with UI:
```bash
npm run test:ui
```

Run tests with coverage:
```bash
npm run test:coverage
```

## 🎯 Usage Guide

### 1. Set Your Location
- Enter your city name in the header location input
- Click "Set" to load weather data for your location

### 2. Complete Your Profile
- Click "Profile" in the header
- Fill in family details, housing type, and special requirements
- This helps generate personalized recommendations

### 3. Generate Preparedness Plan
- Navigate to "Preparedness Plan" tab
- Click "Generate Preparedness Plan"
- Review AI-generated recommendations
- Save the plan for future reference

### 4. Create Emergency Checklists
- Go to "Emergency Checklist" tab
- Select a scenario (flood, cyclone, etc.)
- Generate and track your checklist items

### 5. Get Travel Advisory
- Navigate to "Travel Advisory" tab
- Enter your destination
- Get AI-powered travel recommendations

### 6. Monitor Real-time Alerts
- Check "Real-time Alerts" tab
- View current weather alerts
- Alerts auto-refresh every 5 minutes

### 7. Use Multilingual Support
- Go to "Multilingual" tab
- Select your preferred language
- Translate safety information

### 8. Chat with AI Assistant
- Navigate to "AI Assistant" tab
- Ask questions about monsoon safety
- Get instant AI-powered responses

## 🆘 Troubleshooting

### Common Issues

**API Key Errors**
- Verify your API keys are correct in `.env`
- Ensure API keys have proper permissions
- Check API key quotas and limits

**Weather Data Not Loading**
- Verify OpenWeatherMap API key
- Check location name spelling
- Ensure internet connection

**AI Features Not Working**
- Verify Gemini API key
- Check API quota limits
- Ensure proper prompt formatting

**Firebase Errors**
- Verify Firebase configuration
- Check Firebase project status
- Ensure proper Firebase rules
