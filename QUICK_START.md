# Quick Start Guide - Monsoon Preparedness AI

## ⚡ 5-Minute Setup

### Step 1: Get API Keys (2 minutes)

**Google Gemini API:**
1. Go to https://makersuite.google.com/app/apikey
2. Click "Create API Key"
3. Copy the key

**OpenWeatherMap API:**
1. Go to https://openweathermap.org/api
2. Sign up (free)
3. Copy your API key from the dashboard

### Step 2: Configure Environment (1 minute)

Create a `.env` file in the project root:

```env
VITE_GEMINI_API_KEY=paste_your_gemini_key_here
VITE_OPENWEATHER_API_KEY=paste_your_openweather_key_here
```

### Step 3: Run the App (1 minute)

```bash
npm run dev
```

Open http://localhost:3000

### Step 4: Test the Features (1 minute)

1. **Enter Location**: Type "Mumbai" and click "Set"
2. **Complete Profile**: Click "Profile" and fill in details
3. **Generate Plan**: Go to "Preparedness Plan" and click generate
4. **Test AI Chat**: Go to "AI Assistant" and ask a question

## 🔧 Troubleshooting

**API Key Errors:**
- Verify keys are correct in `.env`
- Restart dev server after adding `.env`

**Weather Not Loading:**
- Check OpenWeatherMap API key
- Verify internet connection
- Try a different city name

**AI Features Not Working:**
- Check Gemini API key
- Verify API quota limits
- Check console for errors
